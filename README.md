# ASHIK MS — BEE.225 Portfolio

Personal portfolio website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure
- `style.css` — design and responsive layout
- `script.js` — interactions (intro screen, skills, project filter, particles, GitHub API, contact form)
- `assets/ashik.jpg` — profile photo

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a repository and upload all files (keep the `assets` folder).
2. Go to **Settings → Pages**.
3. Under *Build and deployment*, choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Save. The site goes live at `https://<username>.github.io/<repo>/`.

## Add your real projects
Edit the `P` array in `script.js` and add a `repo:"https://github.com/nilakhandan/<repo-name>"` link only for verified repositories.
